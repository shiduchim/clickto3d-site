How it works

  1. Open a plan view (floor, ceiling, structural or area plan).
  2. Run ClickToSection from the Add-Ins tab.
  3. Click where the section should cut.
  4. Move the mouse toward the side you want to look at. A small marker shows the direction.
  5. When the mouse passes the dashed circle, the section opens, looking that way.

Esc or right-click cancels.

What it does

  • Reuses one section view, so the project doesn’t fill up with views. Each user gets their own in a workshared model.
  • Keeps the size you drag the section to, wherever you place it next.
  • Each placement is one Undo step.
  • Follows Revit’s light and dark theme.

Settings

Width, depth, height, Below level, “Use level above for height”, Feet or Meters, marker size and color, Snap to 90°.
